# Consolidated manual-testing gates

All items start **pending**. Builds, fixture tests, screenshots, and CI do not
mark these passed. Record date, commit, macOS/hardware, account/scope (without
secrets), actual result, and evidence when a person executes a check.

- [Desktop and appearance](desktop-and-appearance.md): app, panel, widget, branded DMG and icon checks.
- [Measurements and sync](measurements-and-sync.md): provider, attribution, quota, permissions, and persistence.

Update these domain guides instead of making one TODO file per bug or PR.
Agent-operated UI testing requires an explicit request under [AGENTS](../../AGENTS.md).
